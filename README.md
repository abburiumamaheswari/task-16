# Task 16 – Selecting Rows and Columns with loc and iloc

## Internship
Veda Technology – Data Science Internship

## Objective
To practice selecting rows and columns using Pandas `loc[]` and `iloc[]` and understand the difference between label-based and position-based selection.

## Tools Used
- Python
- Pandas
- Jupyter Notebook / Google Colab

## Concepts Covered
- Label-based indexing using `loc[]`
- Position-based indexing using `iloc[]`
- Selecting individual rows and columns
- Selecting multiple rows and columns
- Row slicing and column slicing
- Conditional selection

## Programs Implemented

### loc[] Examples
1. Selecting a single row.
2. Selecting multiple rows.
3. Selecting a single column.
4. Selecting specific rows and columns.
5. Selecting rows using label slicing.

### iloc[] Examples
1. Selecting a single row.
2. Selecting multiple rows.
3. Selecting a single column.
4. Selecting specific rows and columns.
5. Selecting rows using integer positions.

## Comparison
- `loc[]` selects data using labels.
- `iloc[]` selects data using integer positions.
- `loc[]` includes the ending label in slicing.
- `iloc[]` excludes the ending position in slicing.
